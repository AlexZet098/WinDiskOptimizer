# WinDiskOptimizer

Полноценная утилита для анализа, визуализации и оптимизации дискового пространства.

## Возможности
- Автоматическое определение дисков и выбор произвольных точек монтирования.
- Анализ занимаемого места с учётом предустановленных профилей: **fast (Быстро)**, **safe (Безопасно)** и **aggressive (Агрессивно)**.
- Глубокий скан выбранных папок или дисков с ограничением глубины по профилю.
- Поиск крупных файлов и оценка потенциальной экономии.
- Рекомендации по очистке: временные каталоги, устаревшие файлы с расширениями `.tmp`, `.log`, `.bak`, `.old`, а также обнаруженные крупные объекты.
- Построение диаграмм (pie/bar) по использованию диска и распределению пространства по каталогам/файлам с подсказками при наведении.

## Быстрый старт
1. Убедитесь, что установлен Python 3.10+ и (по желанию для графиков) библиотека `matplotlib`.
2. Графический интерфейс (Windows 10/11 и другие ОС с Tk):
   ```bash
   PYTHONPATH=src python -m windiskoptimizer.gui
   ```
   Выберите диски, профиль и папки для глубокого сканирования — результаты и интерактивные графики (подсказки с путями и размером при наведении) отображаются прямо в окне.
3. CLI по умолчанию:
   ```bash
   PYTHONPATH=src python -m windiskoptimizer.cli
   ```
4. CLI с ручным выбором дисков и глубоким сканированием:
   ```bash
   PYTHONPATH=src python -m windiskoptimizer.cli --disks / /mnt/data --deep-scan /var/log /home/user/Downloads
   ```
5. CLI с выбором профиля:
   ```bash
   PYTHONPATH=src python -m windiskoptimizer.cli --profile aggressive
   ```
6. В CLI диаграммы сохраняются в папку `charts` (можно изменить через `--chart-dir`). Если `matplotlib` не установлен, текстовый отчёт всё равно будет сформирован.

## Сборка и запуск через .exe на Windows 10/11
1. Установите Python 3.10+ и Git. Создайте/активируйте виртуальное окружение: `python -m venv venv && venv\Scripts\activate`.
2. Установите зависимости и PyInstaller:
   ```bat
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt pyinstaller
   ```
3. Соберите исполняемый файл (GUI и CLI) одной командой:
   ```bat
   pyinstaller --clean --noconfirm WinDiskOptimizer.spec
   ```
   - `WinDiskOptimizer.exe` (GUI) появится в `dist\WinDiskOptimizer\`.
   - `WinDiskOptimizerCLI.exe` (CLI) появится в `dist\WinDiskOptimizerCLI\`.
4. Запустите GUI без поиска файлов вручную: двойной клик по `WinDiskOptimizer.exe`.
   - Все отчёты и графики отображаются прямо в окне (гистограмма/круговая диаграмма по выбору, подсказки с путём и размером при наведении).
5. Для быстрой сборки в будущем можно использовать скрипт `scripts\build_windows_exe.bat` (запускайте из PowerShell или CMD из каталога `scripts`).

## Профили
- **fast** — поверхностный анализ верхних уровней каталога, минимум рекомендаций.
- **safe** (по умолчанию) — сбалансированный анализ с умеренной глубиной обхода.
- **aggressive** — самый глубокий анализ, учитывает симлинки и предлагает больше вариантов очистки.
